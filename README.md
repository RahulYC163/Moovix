# 🎬 Moovix - Movie Browser App

Moovix is a sleek and responsive React-based movie browsing app powered by the TMDB API. It allows users to explore popular, top-rated, and upcoming movies with features like dark mode, filtering by rating, and sorting options.

## 🚀 Features

- 🔥 Browse **Popular**, ⭐ **Top Rated**, and 🎉 **Upcoming** movies
- 🌓 **Dark/Light Mode** toggle with theme persistence using `localStorage`
- 📊 **Filter by Rating** (8+, 7+, 6+)
- ↕️ **Sort by Release Date** or **Rating** (ascending/descending)
- 🎥 Movie details: Poster, Title, Release Date, Overview, and Rating
- 🧭 Intuitive **navigation** using `React Router`

## 🛠 Tech Stack

- **React**
- **React Router**
- **TMDB API**
- **Lodash** (for sorting)
- **CSS** (custom styles)
- **LocalStorage** (for theme persistence)
